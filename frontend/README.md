# beKind Donation Frontend

A clean, screenshot-ready frontend for the existing beKind Django donation application.

Screens:
- Donation / UPI-style contribution page
- Live Donor Wall

Run:
```bash
cd frontend
npm install
npm run dev
```

The UI is presentation/demo ready. The existing Django backend remains unchanged.
Connect the form submit to the Django donation endpoint when the backend is repaired/available.
